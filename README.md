# onlinetest.az – QA Test Documentation

Bu repo **https://onlinetest.az/** layihəsi üzrə QA sənədlərini (test case, bug report, checklist, test summary) saxlayır.

## Layihə haqqında
- **Sayt:** https://onlinetest.az/
- **QA mühəndisi:** (adınız)
- **Test növləri:** Manual (Functional, UI/UX, Compatibility, Negative, Basic Security)

## Test mühiti
| Parametr | Dəyər |
|---|---|
| OS | Windows 11 / Android / iOS |
| Brauzer | Chrome, Firefox, Edge, Safari |
| Cihaz | Desktop, Mobile, Tablet |

## Folder strukturu
| Folder | Təsvir |
|---|---|
| `docs/` | Test plan, strategiya, tələblərin analizi, mühit məlumatı |
| `test-cases/` | Modullar üzrə test case-lər |
| `checklists/` | Smoke, regression, UI, form validation, release checklist |
| `bug-reports/` | Bug report-lar və bug tracker |
| `test-summary/` | Sprint/Release üzrə test hesabatları |
| `test-data/` | Valid, invalid və boundary test datalar |
| `templates/` | Hazır şablonlar |
| `evidence/` | Ümumi screenshot və video sübutlar |
| `automation/` | Gələcək avtomatlaşdırma (Postman və s.) |

## Adlandırma qaydaları
- Test case: `TC_001`, `TC_002` ...
- Bug: `BUG-001`, `BUG-002` ...
- Summary: `Test-Summary_Sprint-01.md`
